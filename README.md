# Walkie – גרסת ווב לבודקים

ניווט רגלי ותחבורה ציבורית. גרסה זו רצה כולה בדפדפן (בלי שרת) ומתאימה ל"הוספה למסך הבית" באייפון.

**התקנה באייפון:** לפתוח את הקישור ב-Safari ← כפתור השיתוף ← "הוסף למסך הבית".

> זמני הגעה בזמן אמת לא זמינים בגרסת הווב (המקור לא מאפשר גישה מדפדפן) – מוצגים זמנים לפי לוח הזמנים.

נבנה מתוך הקוד עם `npm run web:build`.
